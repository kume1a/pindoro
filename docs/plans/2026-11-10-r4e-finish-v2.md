# R4e Finish v2.0 Implementation Plan

> **For agentic workers:** Implement this plan one task at a time. Steps use checkbox (`- [ ]`)
> syntax for tracking. Commits need the user's approval each time (`~/.claude/CLAUDE.md`): build
> the tasks, then ask before committing them, one commit per task.

**Goal:** The designed v2.0 parts R4b–R4d left out: the Unit guide and See the streets, Hear the
name, resuming a killed lesson, the Path's loading skeletons and the turn-list setting.

**Architecture:** Resume is a pindoro_core rule (`LessonRun.saved` / `LessonRun.restore`) over a
one-row `saved_lesson` table: the plan is re-made from a saved seed and the answers replayed.
`startLocation` opens a saved lesson. The Unit guide is a course-layer screen over
`courseProvider`. Hear the name is a `Speech` service in `core` over `flutter_tts`. `Signpost`
gains a book button and pindoro_design a `Skeleton`.

**Tech Stack:** Dart 3 / Flutter 3.47.9, Riverpod 3 (no codegen), go_router, Drift, gen-l10n ARB,
`flutter_tts`.

```dart
// LessonRules
static const Duration resumeFor = Duration(hours: 24);

/// An answer by the index of the step it answered (a saved lesson).
typedef SavedAnswer = ({int step, String streetId, Tier tier, int xp, double? distanceM, DateTime at});

// LessonRun
List<SavedAnswer> get saved => [
  for (final a in answers)
    (
      step: steps.indexWhere((s) => identical(s, a.step)),
      streetId: a.step.street.id,
      tier: a.tier,
      xp: a.xp,
      distanceM: a.distanceM,
      at: a.at,
    ),
];

/// [steps] (as planned, before fixes) with [answers] replayed and walked on
/// to [index]; null when an answer doesn't fit its step (the plan changed).
static LessonRun? restore(LessonKind kind, List<LessonStep> steps, List<SavedAnswer> answers, int index) {
  var run = LessonRun(kind, steps);
  for (final a in answers) {
    while (run.index < a.step && !run.finished) {
      run = run.next();
    }
    if (run.finished || run.index != a.step) return null;
    final step = run.step;
    if (step is! TestStep || step.street.id != a.streetId) return null;
    run = run._answer((step: step, tier: a.tier, xp: a.xp, distanceM: a.distanceM, at: a.at));
  }
  while (run.index < index && !run.finished) {
    run = run.next();
  }
  return run;
}

/// Where a restored run continues: past a reveal that was showing.
LessonRun resumeAt() => answered ? next() : this;
```

`course.dart`: `CourseRules.axisShare = 0.4`; `mainAxis` projects every segment with
`LocalProjection(first point)`, bearing `atan2(dx, dy)` in degrees folded to `[0, 180)`, bin
`((deg + 22.5) % 180 ~/ 45)` → `StreetAxis.values[bin]`, weights = segment length; returns the top
bin when `top / total >= axisShare`, else null (and null with no length).
