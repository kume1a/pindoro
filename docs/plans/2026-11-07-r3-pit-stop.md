# R3 Pit stop Implementation Plan

> **For agentic workers:** Implement this plan one task at a time. Steps use checkbox (`- [ ]`)
> syntax for tracking. The user approved this batch's git flow: worktree `../pindoro-r3`, branch
> `r3-pit-stop`, one commit per task, PR, merge commit once CI is green.

**Goal:** Pit stop spaced repetition (review items, Pit stop screen and round, Home card) plus the
Reveal/Results Pit stop chips and the mastered district rows (spec:
`docs/specs/2026-11-07-r3-pit-stop-design.md`).

**Architecture:** `pindoro_core` `nextReview` is the step rule. `ProgressDao.recordAnswer` keeps
a `review_item` row per city and street in the same transaction. Screens read the items through the
DAO and keep the streets still in the pack. A Pit stop round is a normal round with
`round.pit_stop` set.

**Tech Stack:** Flutter, Riverpod 3, Drift (schema 7), go_router, gen-l10n.

## Global Constraints

- Design values only from `pindoro_design` tokens; never hand-edit generated code; `just gen`.
- Never uppercase UI strings; numbers through `formatNumber`; every string in both `.arb` files.
- Layers: `l10n` → `core` → `features/progress` → `features/pack` → `features/map` → screen
  features → `app`; screen features never import each other.
- Intervals 1, 3, 7, 21 days; two Greats in a row graduate; Close advances and breaks the run; a
  Miss resets to step 1; a Pit stop asks at most 10 streets, most overdue first.
- Run only the touched tests locally; CI runs everything.
