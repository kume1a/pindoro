# M1 Gameplay Implementation Plan

> **For agentic workers:** Implement this plan one task at a time, pausing for review between tasks. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Playable, resumable 10-question rounds (pick area + difficulty → pin → score → answer log →
results → XP/level) with the full Tbilisi pack downloaded silently from `/v1/catalog`.

**Architecture:** Pure rules (`Area`, `Difficulty.pool`, `knowledgeFrom`) live in `pindoro_core`.
The app adds schema v2 (`round_question`), a `PackStore` that installs verified packs into the
documents dir, a Riverpod `RoundController` that drives a round from the DB (so it resumes after an
app kill), and real Quiz / Results / Home / Area screens. The MapLibre map is injected through a
provider so widget tests never build the platform view.

**Tech Stack:** Flutter 3.47 / Dart 3.13, flutter_riverpod 3, go_router 17, drift 2.35 (+ drift_dev
make-migrations), sqlite3 3, maplibre_gl 0.27, http (+ `http/testing.dart` MockClient), crypto.

Spec: `docs/specs/2026-11-06-m1-gameplay-design.md`.

## Global Constraints

- Difficulty pools are cumulative: easy = {easy}; medium = {easy, medium}; hard = + hard; expert = all four.
- Scoring area: `city.area_m2` for the whole city, `district.area_m2` for a district; scoring only through `scoreAnswer` (pindoro_core).
- Round size 10 (`QuestionSelector.roundSize`); exclude the last 30 answered streets (`recentlyAnsweredStreetIds(limit: 30)`).
- Packs: `<documents>/packs/<city>/<version>.sqlite`, versions `YYYYMMDDTHHMMSSZ` compared as strings, keep the 2 newest, `format_version` must be 1, verify size + sha256 of the `.gz` before gunzip. Failures keep the current pack, are silent, logged only in debug builds.
- `answer` stays append-only (trigger); the current question is derived (first planned position without an answer), never stored.
- Map sources: `you-pin`, `truth-street`, `measure`, `area-mask`. Colours: yellow = truth, cobalt = you, ink = measurement.
- Design values only from `tokens.json` (regenerate with `dart run packages/pindoro_design/tool/generate_tokens.dart`); never uppercase UI strings; FiraGO with tabular figures comes from the theme.
- Dart style: explicit return types, single quotes, trailing commas, `dart format` clean, `flutter analyze --fatal-infos` clean (run from repo root).
- Run only the tests that cover the change (per task commands below). Commits/pushes only at approved checkpoints, no Co-Authored-By trailer.

## Spec adjustments made while planning

1. `Area` resolves name, `areaM2`, bbox and boundary in one lookup: `Area.shapeIn(pack) → AreaShape?` (instead of separate `areaM2()` / `boundary()`).
2. `PackRepository.streetNames(ids)` is added so Results can show names without decoding every street's geometry.
3. `lastTierByStreet()` returns the map for every answered street (no id filter) — the answer log is small.
4. Pack refresh runs on launch only (first launch refreshes before the player reaches Area, so the city-pick refresh is redundant).
5. A freshly installed pack becomes active immediately (`packRepositoryProvider` is invalidated); a round in play is unaffected because the controller holds its own `Street` objects. This replaces "active from the next round start".

import '../geo/geo.dart';
import '../pack/pack_repository.dart';

/// Name, size and outline of an area as found in a pack.
typedef AreaShape = ({
  String name,
  double areaM2,
  Bbox bbox,
  List<List<Polyline>> boundary,
});

/// What a round covers: the whole city or one district of the pack.
sealed class Area {
  const Area();

  /// Parses the JSON stored in `user_settings.last_area_json` / `round.area_json`.
  factory Area.fromJson(Map<String, Object?> json) => switch (json) {
    {'kind': 'city'} => const WholeCity(),
    {'kind': 'district', 'district_id': final String id} => DistrictArea(id),
    _ => throw FormatException('Not an area: $json'),
  };

  /// Null for the whole city.
  String? get districtId;

  Map<String, Object?> toJson();

  /// Null when the pack doesn't contain this area (e.g. the offline fixture).
  AreaShape? shapeIn(PackRepository pack);
}

final class WholeCity extends Area {
  const WholeCity();

  @override
  String? get districtId => null;

  @override
  Map<String, Object?> toJson() => {'kind': 'city'};

  @override
  AreaShape shapeIn(PackRepository pack) {
    final city = pack.city();
    return (
      name: city.nameKa,
      areaM2: city.areaM2,
      bbox: city.bbox,
      boundary: city.boundary,
    );
  }

  @override
  bool operator ==(Object other) => other is WholeCity;

  @override
  int get hashCode => (WholeCity).hashCode;
}

final class DistrictArea extends Area {
  const DistrictArea(this.districtId);

  @override
  final String districtId;

  @override
  Map<String, Object?> toJson() => {
    'kind': 'district',
    'district_id': districtId,
  };

  @override
  AreaShape? shapeIn(PackRepository pack) {
    for (final d in pack.districts()) {
      if (d.id == districtId) {
        return (
          name: d.nameKa,
          areaM2: d.areaM2,
          bbox: d.bbox,
          boundary: d.boundary,
        );
      }
    }
    return null;
  }

  @override
  bool operator ==(Object other) =>
      other is DistrictArea && other.districtId == districtId;

  @override
  int get hashCode => districtId.hashCode;
}

```dart
  /// Inserts the round and its planned streets atomically; returns the round id.
  Future<String> startRound({
    required String cityId,
    required Area area,
    required Difficulty difficulty,
    required String packVersion,
    required List<String> streetIds,
  }) => transaction(() async {
    final round = await into(rounds).insertReturning(
      RoundsCompanion.insert(
        cityId: cityId,
        areaJson: jsonEncode(area.toJson()),
        difficulty: difficulty,
        packVersion: packVersion,
      ),
    );
    await batch(
      (b) => b.insertAll(roundQuestions, [
        for (final (i, streetId) in streetIds.indexed)
          RoundQuestionsCompanion.insert(
            roundId: round.id,
            position: i,
            streetId: streetId,
          ),
      ]),
    );
    return round.id;
  });

  /// The most recent round while it is unfinished; starting a new round
  /// abandons older unfinished ones.
  Future<Round?> resumableRound() async {
    final latest =
        await (select(rounds)
              ..orderBy([(_) => OrderingTerm.desc(_rowid)])
              ..limit(1))
            .getSingleOrNull();
    return latest?.finishedAt == null ? latest : null;
  }

  Future<RoundProgress> roundProgress(String roundId) async => (
    round: await (select(
      rounds,
    )..where((r) => r.id.equals(roundId))).getSingle(),
    planned:
        await (select(roundQuestions)
              ..where((q) => q.roundId.equals(roundId))
              ..orderBy([(q) => OrderingTerm.asc(q.position)]))
            .map((q) => q.streetId)
            .get(),
    answers: await answersForRound(roundId),
  );

  Future<void> finishRound(String roundId) =>
      (update(rounds)..where((r) => r.id.equals(roundId))).write(
        RoundsCompanion(finishedAt: Value(DateTime.now())),
      );

  Future<List<Answer>> answersForRound(String roundId) =>
      (select(answers)
            ..where((a) => a.roundId.equals(roundId))
            ..orderBy([(_) => OrderingTerm.asc(_rowid)]))
          .get();

  /// Latest tier per answered street (selection weights).
  // ponytail: reads the whole answer log; aggregate in SQL past ~100k answers.
  Future<Map<String, Tier>> lastTierByStreet() async => {
    for (final a in await (select(
      answers,
    )..orderBy([(_) => OrderingTerm.asc(_rowid)])).get())
      a.streetId: a.tier,
  };

  Future<Set<String>> recentlyAnsweredStreetIds({int limit = 30}) async => {
    for (final a
        in await (select(answers)
              ..orderBy([(_) => OrderingTerm.desc(_rowid)])
              ..limit(limit))
            .get())
      a.streetId,
  };
```

import 'dart:convert';
import 'dart:io';

import 'package:crypto/crypto.dart';
import 'package:flutter/foundation.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';
import 'package:http/http.dart' as http;
import 'package:sqlite3/sqlite3.dart';

import '../../app/config.dart';

/// Overridden in main() with the app documents directory.
final packStoreProvider = Provider<PackStore>(
  (ref) => throw UnimplementedError('packStoreProvider must be overridden'),
);

typedef CatalogPack = ({
  String version,
  String url,
  String sha256,
  int size,
  int formatVersion,
});

/// Installs the packs listed by `/v1/catalog` as `<root>/<city>/<version>.sqlite`.
class PackStore {
  PackStore({required this.root, required this.apiBaseUrl, http.Client? client})
    : _client = client ?? http.Client();

  static const int supportedFormatVersion = 1;
  static const int keptVersions = 2;

  final Directory root;
  final String apiBaseUrl;
  final http.Client _client;

  /// Newest installed pack of [city]; versions sort lexically.
  File? newest(String city) => _installed(city).firstOrNull;

  /// Installs the catalog's pack for [city] when it is newer than the newest
  /// installed one. Returns the new file, or null when there was nothing to do.
  /// Throws on network or verification failures; nothing partial is left.
  Future<File?> refresh(String city) async {
    final pack = await _catalogPack(city);
    if (pack == null || pack.formatVersion > supportedFormatVersion) return null;
    final current = newest(city);
    if (current != null && _version(current).compareTo(pack.version) >= 0) {
      return null;
    }

    final dir = Directory('${root.path}/$city')..createSync(recursive: true);
    final tmp = File('${dir.path}/${pack.version}.download');
    try {
      // ponytail: whole pack in memory (~1 MB gz); stream to disk past a few MB.
      final uri = Uri.parse(pack.url);
      final res = await _client.get(uri);
      if (res.statusCode != 200) {
        throw HttpException('HTTP ${res.statusCode}', uri: uri);
      }
      final gz = res.bodyBytes;
      if (gz.length != pack.size) {
        throw FormatException('size ${gz.length} != ${pack.size}');
      }
      if (sha256.convert(gz).toString() != pack.sha256) {
        throw const FormatException('sha256 mismatch');
      }
      await tmp.writeAsBytes(gzip.decode(gz), flush: true);
      if (_formatVersion(tmp) != supportedFormatVersion) {
        throw const FormatException('unsupported pack format');
      }
      final installed = await tmp.rename('${dir.path}/${pack.version}.sqlite');
      for (final old in _installed(city).skip(keptVersions)) {
        old.deleteSync();
      }
      return installed;
    } finally {
      if (tmp.existsSync()) tmp.deleteSync();
    }
  }

  /// Installed packs of [city], newest first.
  List<File> _installed(String city) {
    final dir = Directory('${root.path}/$city');
    if (!dir.existsSync()) return const [];
    return dir
        .listSync()
        .whereType<File>()
        .where((f) => f.path.endsWith('.sqlite'))
        .toList()
      ..sort((a, b) => b.path.compareTo(a.path));
  }

  Future<CatalogPack?> _catalogPack(String city) async {
    final uri = Uri.parse('$apiBaseUrl/v1/catalog');
    final res = await _client.get(uri);
    if (res.statusCode != 200) {
      throw HttpException('HTTP ${res.statusCode}', uri: uri);
    }
    final catalog =
        jsonDecode(utf8.decode(res.bodyBytes)) as Map<String, Object?>;
    for (final entry in (catalog['cities']! as List<Object?>)
        .cast<Map<String, Object?>>()) {
      if (entry['id'] != city) continue;
      final p = entry['pack']! as Map<String, Object?>;
      return (
        version: p['version']! as String,
        url: p['url']! as String,
        sha256: p['sha256']! as String,
        size: p['size']! as int,
        formatVersion: p['format_version']! as int,
      );
    }
    return null;
  }
}

String _version(File pack) =>
    pack.uri.pathSegments.last.replaceFirst('.sqlite', '');

int? _formatVersion(File pack) {
  final db = sqlite3.open(pack.path, mode: OpenMode.readOnly);
  try {
    final rows = db.select(
      "SELECT value FROM meta WHERE key = 'format_version'",
    );
    return rows.isEmpty ? null : int.tryParse(rows.first['value'] as String);
  } finally {
    db.close();
  }
}

/// Background refresh: true when a new pack was installed. Failures keep the
/// current pack and are logged in debug builds only.
Future<bool> refreshQuietly(PackStore store) async {
  try {
    return await store.refresh(AppConfig.cityId) != null;
  } catch (e) {
    if (kDebugMode) debugPrint('pack refresh failed: $e');
    return false;
  }
}

/// What a round needs while it is played.
class RoundContext {
  const RoundContext({
    required this.id,
    required this.shape,
    required this.difficulty,
    required this.packVersion,
    required this.questions,
    required this.index,
  });

  final String id;
  final AreaShape shape;
  final Difficulty difficulty;
  final String packVersion;

  /// Planned streets present in the active pack, in round order.
  final List<Street> questions;
  final int index;

  Street get current => questions[index];
  int get number => index + 1;
  int get total => questions.length;
  bool get isLast => index == questions.length - 1;

  RoundContext advance() => RoundContext(
    id: id,
    shape: shape,
    difficulty: difficulty,
    packVersion: packVersion,
    questions: questions,
    index: index + 1,
  );
}

  const RoundState();
}

final class RoundLoading extends RoundState {
  const RoundLoading();
}

final class RoundNotEnough extends RoundState {
  const RoundNotEnough(this.count);

  final int count;
}

final class RoundAreaMissing extends RoundState {
  const RoundAreaMissing();

final class RoundFinished extends RoundState {
  const RoundFinished(this.roundId);

  final String roundId;
}

sealed class RoundInPlay extends RoundState {
  const RoundInPlay(this.round, this.pin);

  final RoundContext round;
  final LatLng? pin;

final class RoundAsking extends RoundInPlay {
  const RoundAsking(super.round, [super.pin]);
}

final class RoundRevealed extends RoundInPlay {
  const RoundRevealed(
    super.round,
    LatLng super.pin, {
    required this.answer,
    required this.nearest,
  });

  final Answer answer;

  /// Closest point of the street to the pin (end of the measure line).
  final LatLng nearest;
}

class RoundController extends Notifier<RoundState> {
  bool _saving = false;

  @override
  RoundState build() => const RoundLoading();

  AppDatabase get _db => ref.read(databaseProvider);

  Future<void> start(Area area, Difficulty difficulty) async {
    state = const RoundLoading();
    final pack = await ref.read(packRepositoryProvider.future);
    final shape = area.shapeIn(pack);
    if (shape == null) {
      state = const RoundAreaMissing();
      return;
    }
    final streets = pack.streets(
      districtId: area.districtId,
      difficulties: difficulty.pool,
    );
    final lastTiers = await _db.lastTierByStreet();
    final recent = await _db.recentlyAnsweredStreetIds();
    final selection = ref
        .read(questionSelectorProvider)
        .select([
          for (final s in streets)
            QuestionCandidate(
              streetId: s.id,
              midpoint: s.midpoint,
              knowledge: knowledgeFrom(lastTiers[s.id]),
            ),
        ], recentlyAsked: recent);
    switch (selection) {
      case NotEnoughStreets(:final count):
        if (ref.mounted) state = RoundNotEnough(count);
      case SelectedQuestions(:final streetIds):
        final byId = {for (final s in streets) s.id: s};
        final packVersion = pack.meta()['version']!;
        final roundId = await _db.startRound(
          cityId: pack.city().id,
          area: area,
          difficulty: difficulty,
          packVersion: packVersion,
          streetIds: streetIds,
        );
        if (!ref.mounted) return;
        state = RoundAsking(
          RoundContext(
            id: roundId,
            shape: shape,
            difficulty: difficulty,
            packVersion: packVersion,
            questions: [for (final id in streetIds) byId[id]!],
            index: 0,
          ),
        );
    }
  }

  Future<void> resume(String roundId) async {
    state = const RoundLoading();
    final pack = await ref.read(packRepositoryProvider.future);
    final progress = await _db.roundProgress(roundId);
    if (!ref.mounted) return;
    final area = Area.fromJson(
      jsonDecode(progress.round.areaJson) as Map<String, Object?>,
    );
    final shape = area.shapeIn(pack);
    if (shape == null) {
      state = const RoundAreaMissing();
      return;
    }
    // Street ids are stable across pack versions; streets retired since are skipped.
    final byId = {
      for (final s in pack.streets(districtId: area.districtId)) s.id: s,
    };
    final questions = [for (final id in progress.planned) ?byId[id]];
    final answered = {for (final a in progress.answers) a.streetId};
    final index = questions.indexWhere((s) => !answered.contains(s.id));
    if (index == -1) {
      await _db.finishRound(roundId);
      if (ref.mounted) state = RoundFinished(roundId);
      return;
    }
    state = RoundAsking(
      RoundContext(
        id: roundId,
        shape: shape,
        difficulty: progress.round.difficulty,
        packVersion: pack.meta()['version']!,
        questions: questions,
        index: index,
      ),
    );
  }

  void placePin(LatLng pin) {
    if (state case RoundAsking(:final round)) state = RoundAsking(round, pin);
  }

  Future<void> confirm() async {
    if (_saving) return;
    if (state case RoundAsking(:final round, pin: final pin?)) {
      _saving = true;
      try {
        final street = round.current;
        final nearest = pointToPolylineDistance(pin, street.geometry);
        final score = scoreAnswer(
          nearest.distanceMeters,
          round.shape.areaM2,
          round.difficulty,
        );
        final answer = await _db
            .into(_db.answers)
            .insertReturning(
              AnswersCompanion.insert(
                roundId: round.id,
                streetId: street.id,
                pinLat: pin.lat,
                pinLon: pin.lon,
                distanceM: nearest.distanceMeters,
                tier: score.tier,
                xp: score.xp,
                packVersion: round.packVersion,
              ),
            );
        if (ref.mounted) {
          state = RoundRevealed(
            round,
            pin,
            answer: answer,
            nearest: nearest.nearestPoint,
          );
        }
      } finally {
        _saving = false;
      }
    }
  }

  Future<void> next() async {
    if (state case RoundRevealed(:final round)) {
      if (!round.isLast) {
        state = RoundAsking(round.advance());
        return;
      }
      await _db.finishRound(round.id);
      if (ref.mounted) state = RoundFinished(round.id);
    }
  }
}
