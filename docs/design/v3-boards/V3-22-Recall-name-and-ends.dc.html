Place → name and extent cards

  • Name it (card N) unlocks when the pin card reaches S ≥ 7 d, for skeleton, grid and parent streets (about 800). Forgot = Again, Knew it = Good. Every 10th N review is checked with 6 names including confusables.
  • Extent (card E) for streets over 1.2 km once the pin card reaches S ≥ 7 d. Each end counts within max(150 m, 10 % of length): both → Good, one → Hard, none → Again.
  • The three-option name question is gone as a scored item; it only appears inside an intro as scaffolding.
