Route recitals (R)

  • Weekly random A → B pairs from the gateway phase on; route-book runs once their junctions are Known.
  • Speech is on-device (Vosk Georgian, 45 MB) with a grammar of the city’s street names, turn words and landmarks; the transcript is always shown for one-tap fixes; low confidence falls back to self-grading.
  • Grading: names resolve by fuzzy match + spatial plausibility; Viterbi path on the directed, turn-restricted graph with up to 2 unnamed connectors ≤ 150 m. Stretch ≤ 1.03 Perfect, ≤ 1.25 Great, ≤ 1.60 Close.
  • Failed decisions inside a recital count as Again on those junction cards; correct ones are only logged.
  • Draw mode is the R4 road-trip screen.

Flutter: RecitalGrader.parse(tokens) → JunctionPath; RecitalGrader.score(path, a, b) → {tier, stretch, decisions[]}. New icons: mic, keyboard.
