v3 · replaces the R3–R5 learning mechanics

Learn the whole city: every street, the turns between them, and the way there by heart

One spaced-repetition model (FSRS-6) schedules every street and every key turn. A fixed curriculum feeds it new material: skeleton, then the city-wide grid, then neighbourhood by neighbourhood from the centre and home. The pin on a blank map stays the core move. Route recitals and real GPS-free drives are the tests.

Removed

  • XP per answer, daily XP goal, levels
  • Weekly leagues (ranked by XP)
  • The Path (240-street ceiling) and Jump ahead
  • Pit stop as a separate tab and its 1 / 3 / 7 / 21-day steps
  • Difficulty by road class as a setting (kept as a filter in Explore)
  • “Known after one good answer” that never decays
  • Three-option name question as a scored item

Changed

  • Home → Today tab: one session a day, sized by minutes
  • Reveals: the XP chip becomes “next review in N days”
  • Scoring: absolute distance plus which street the pin snaps to; look-alikes are mix-ups
  • Lessons → intros mixed into reviews, groups of 3, retrieved twice the same day
  • Road trip → recital “Draw” mode, graded on the directed, turn-restricted graph
  • Streak counts only when due reviews are cleared
  • Free play → Explore; its answers feed the memory model
  • Badges → neighbourhood and district Mastered

New

  • Placement (about 15 min) per city
  • Name it (place → name) and Extent (both ends) cards
  • Family sweep, crossings drill, bearing questions
  • Junction, gateway, bridge and landmark cards
  • Route recital by voice, typing or drawing
  • GPS-free drive mode with track review
  • Progress: City memory, recall rate, forecast, whole-city date
  • Personal landmarks; Learning settings
